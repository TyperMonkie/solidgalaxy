# 裂缝结构的连续变化

## 原来的限制

旧实现总是使用18个近乎均匀排列的球面点，seed 只改变少量角度。裂缝始终是这些区域的边界，扰动、宽度和覆盖方式固定。因此虽然每次顶点位置不同，整体仍然是同一种龟裂网络；之前不能把“不同种子”描述为“明显不同的地貌设计”。

## 当前实现

`FractureField.ts` 和 `shaders/fractures.glsl` 提供连续组合的结构场。`geometry.fractures` 包含七个0–1参数：区域密度、分流比重、定向拉伸、弯曲扰动、宽度、局部覆盖、切割深度。它们组合工作，没有把用户分进几种裂缝模板。区域中心不再采用固定点阵，数量在6–32之间；轴向、点位、区域活动和扰动由种子稳定展开。

不规则板块边界、主裂谷和邻近细支流经宽度加权联合。局部活动场允许大片完整地表。沟壑位移、颜色和发光采用同一个场；社交远景复用该场，仍不计算近景的真实位移和精细法线。发光量独立控制，允许暗色干燥裂谷。

旧 RenderSpec 可省略新字段，运行时由 seed 得到稳定参数，不改写帖子或保存世界。新 AI 编译必须显式输出七个参数，其他地貌使用 null；校验会拒绝错用结构参数或越界值。Profile Agent 描述表面分布与节奏，Style Compiler 依整体方向选择连续参数。新 seed 在保留参数意图的同时改变点位与方向；重新生成完整宇宙仍会经过 AI 解释和编译。

## 验证与边界

- 构建及22项测试通过；包括旧世界兼容、参数越界拒绝、种子复现、改变种子时保留显式结构意图、点位与朝向变化、多个种子在七条轴上的分布范围。
- `/?fracture-study=1` 对照页使用相同 seed、配色、相机、基础地形与光照，只改变裂缝参数。三个样本用于观察参数差异，生成系统不在它们之间选择。支持自由参数组合与换种子；浏览器实测，两种按钮均改变预期状态，未观察到着色器错误。初始对照关闭动画，允许拖动查看背面。
- 使用相同 seed 的两份虚构 DNA 方向调用真实编译服务，均 `degraded:false`：局部浅痕得到 density .06 / branching .03 / coverage .07 / depth .14；定向分流得到 density .49 / branching .83 / coverage .82 / depth .88，其他参数也不同。分别约20.4秒、24.8秒。这验证编译链路能够输出差异，不能证明所有真实用户输入都会明显不同。
- 截图与该次临时脚本结果保存在被忽略的 `.local/previews/fracture-structure-comparison.jpg` 和 `.local/fracture-ai-smoke.json`。未上传个人内容、运行凭据或本机社交数据。

底层仍有三种地貌家族；本次扩大的是裂缝家族内部的结构自由度，并未实现任意拓扑、任意3D模型或无限风格。有限参数渲染仍可能产生相似结果。其他地貌家族的视觉跨度可继续独立扩展。
