# 云层个性化核查（2026-10-19）

本次检查以当前项目、运行中 API、真实模型输出和 WebGL 画面为依据。结论：新生成链路能控制云层，但之前展示的旧配置、示例居民，以及语义方案趋同，使“参数已经接通”不能等同于“每个人的云明显不同”。

## 发现与修正

- 本地 4173 的 18 颗星球中，1 颗 source=ai 的旧星球没有 weather；它实际使用兼容默认天气。其余 17 颗是预置示例。公网 4183 的 18 颗均为示例，不能据此证明 AI 性格生成。
- 编译输入原先附带三个同种子的完整预设，三个预设天气相同。现已从模型输入移除，预设只用于明确标注的失败降级。
- 新 Profile 输出的每个视觉方向必须给出 weatherIntent。编译必须逐项解释 11 个视觉模块（含禁用理由），云量解释需要考虑密度、透明度、粒径、数量的叠加，而不是只写一个形容词。
- 解释、折衷和手动修改状态随发布持久保存。工作室及社交近景可展开“云层依据与实际参数”；旧配置、示例、当前 AI 输出分别标识。工作室可按当前 DNA 重新编译，无需重新推断人物或强制重新生图；编译失败保留原星球。
- 社交近景此前使用固定 .8 点缩放，工作室使用视口缩放。现在双方按视口高度、FOV、像素比及模型尺度计算云点尺寸，减少同一天气跨页面的表现差异。
- 工作室新发布的原始帖子、兴趣、音乐元数据、图片等保存在服务端源资料区，后续发帖更新继续综合读取；公开 state 不返回该源资料区。旧星球已经丢失的原始输入无法凭空恢复。
- 图片作为真实多模态输入发送，每张附图前增加明确 source ID，避免仅说明图片和真实附图混排时引用错位。
- 修正文档中对裂缝深度和新地形 animation.flow 的过度描述。天气没有按地形、海陆或光照面的定位遮罩；AI 不得承诺“只在某个盆地/背光面有云”，这类要求应作为折衷披露。

## 真实模型与画面验证

模型为配置的 gpt-6-sol。虚构人物使用相同 seed=913721，经过真实 profile → DNA → compile，不手工改天气参数，均 degraded=false。

第一轮三个不同人物的默认方向都选择了稀云：密度分别 -0.62、-0.70、-0.58，粒子 2400、2100、2300。这证实语义方向本身也有趋同，不能拿不同小数当作足够的视觉多样性。随后提示词明确：克制不等于所有人都用稀云、暖米色和慢风；允许有依据的厚云主构图，也不机械选最干燥的方案。

最终核验保留第一轮稀云输出作为对照，并用修订提示词完整生成新的虚构雨夜摄影/叠纸人物：

| 项目 | 坦诚、舒展（第一轮） | 雨夜摄影、叠纸（修订后） |
|---|---:|---:|
| 密度偏移 | -0.62 | 0.43 |
| 单片透明度 | 0.17 | 0.27 |
| 云团尺度 | 0.25 | 0.78 |
| 壳层厚度 | 0.020 | 0.130 |
| 粒径 | 16–36 | 36–82 |
| 配置 / GPU 点数 | 2400 / 2400 | 5700 / 5700 |
| 风速 | 0.004 | -0.004 |
| 云层造成明显像素变化的采样占比 | 约 8.7% | 约 80.2% |

GPU 核对 shader density/opacity/scale、实际粒子数量和尺寸范围与编译输出一致。固定相机、姿态、时间及 balanced 质量，用同一星球有云/无云两张图在内部投影圆盘采样；RGB 最大分量差超过 12/255 计为明显变化。占比是画面差异指标，**不是物理云覆盖率**，也不是不同人物之间的直接像素差。浏览器截图确认前者少量云、后者厚云遮露地表。原始测试输出位于忽略目录 .local，不属于公开用户数据。

## 仍需明确的边界

这组对照证明参数进入实际渲染并能产生显著差异；它不是多样性的统计评估，也没有证明每个性格都必然对应唯一云量。最终厚云案例与稀云案例使用不同版本的提示词，不能视为严格控制其他条件的模型因果实验。更大样本、相同最终提示词下的重复评估仍有价值。

当前渲染的是 Greenheck 的噪声调制云精灵，不是真实体积云。不同字段要共同解释；高重叠可能掩盖密度的细小变化。低画质最多 1800 个云点，星图远景不绘制每颗星球的完整云层，需进入近景观察。

不能把“所有视觉常量都是性格表征”作为已实现结论：个人星球主要艺术输入由编译控制，但共享宇宙背景、相机导航、运行时质量预算、可读性布局等仍是产品/技术设置；legacy modules.stars 没有控制共享背景。它们没有在本次云层修正中伪装成 AI 性格参数。

验证：31 项自动化测试、TypeScript 检查与生产构建通过；本地与公网后端能力目录版本均为 5。未将示例居民改标为 AI 生成，也未自动覆盖用户持久保存的旧星球。
